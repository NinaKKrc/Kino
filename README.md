# Kino
Opis projekta

Pri projektu sem izdelala registracijski obrazec za kino z uporabo HTML-ja in CSS-ja.

- Funkcionalnosti

- Vnos osebnih podatkov

- Vnos kontaktnih podatkov

- Izbira prednostnega kina

- Ustvarjanje in potrditev gesla

- Izbira pogojev in prejemanja promocijskih sporočil

Uporabljene tehnologije

- HTML

- CSS
