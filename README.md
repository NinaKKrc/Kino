# Kino
Opis projekta:
Pri projektu sem izdelala registracijski obrazec za kino. Pri izdelavi sem uporabila HTML za strukturo spletne strani in CSS za oblikovanje ter razporeditev elementov.

Vsebina obrazca

Obrazec je razdeljen na več sklopov:

1. O tebi

- Ime in priimek

- Naslov ulice

- Mesto

- Poštna številka

- Država

- Spol

- Datum rojstva

- Izbira prednostnega kina

2. Kontaktni podatki

- E-poštni naslov

- Telefonska številka

3. Ustvari geslo

- Vnos gesla

- Potrditev gesla

4. Soglasja

- Možnost prejemanja promocijskih e-poštnih sporočil

- Potrditev strinjanja s pogoji in določili programa nagrad

Uporabljene tehnologije:
- HTML

- CSS

Cilj projekta:

Namen projekta je utrditi znanje HTML-ja in CSS-ja ter se naučiti izdelati pregleden spletni obrazec z različnimi vrstami vnosnih polj in možnostmi izbire.
